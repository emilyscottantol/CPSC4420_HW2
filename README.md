# CPSC4420_HW2
Q-Learning Taxi Assignment

This project uses Q-learning to train an agent in the Taxi-v4 environment from Gymnasium. It had different learning rates, discount factors, and epsilon decay values and compares them.

This environment requires Python, Gymnasium, NumPy, Matplotlib and ImageIO libraries

To run it the steps are:
1. Go to Google Colab and open AIAssignment2.ipynb 
2. Install of the libraries that are required
3. Run all the cells one at a time from top to bottom
4. Look at the graphs and evaluate the results
5. Run the cell for the video so it generates the trained taxi agent's video
